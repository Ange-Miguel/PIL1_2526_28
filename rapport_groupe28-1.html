Algorithme de matching

L'algorithme (apps/matching/services.py) calcule un score sur 100 pour chaque paire mentor/mentoré, avec la pondération suivante :

Compétences / matières

45 %

Intersection entre les compétences du mentor et les lacunes du mentoré.

Compatibilité horaire

35 %

Chevauchement en minutes entre les créneaux. Score plein = 120 min de recouvrement.

Proximité de filière

10 %

Même filière = 10 pts, filières différentes = 5 pts (tous IFRI).

Proximité de niveau

10 %

Écart L1→M2 : 0 écart = 10 pts, 1 = 7 pts, 2 = 4 pts, 3+ = 1 pt. Seuil minimum : 20/100.

Section 04

Instructions de Déploiement

Prérequis : Python 3.10+, MySQL 8+, Redis, Git installés sur la machine.

1
Cloner le dépôt
git clone https://github.com/[org]/PIL1_2526_28.git
cd PIL1_2526_28
2
Créer et activer l'environnement virtuel
python -m venv venv
source venv/bin/activate   # Linux/Mac
venv\Scripts\activate      # Windows
3
Installer les dépendances
cd backend
pip install -r requirements.txt

Dépendances principales : Django 4.2+, djangorestframework, djangorestframework-simplejwt, django-cors-headers, channels, channels-redis, mysqlclient, bcrypt, python-dotenv.

4
Configurer les variables d'environnement

Copier et éditer le fichier .env à la racine de backend/ :

SECRET_KEY=changez-moi-en-production
DEBUG=True
DB_NAME=ifri_mentorlink
DB_USER=root
DB_PASSWORD=votre_mdp
DB_HOST=localhost
DB_PORT=3306
REDIS_URL=redis://127.0.0.1:6379
5
Configurer et importer la base de données MySQL

Option A — MySQL en autonome : créer la base puis importer le fichier SQL directement depuis le terminal : 

mysql -u root -p < ../FICHIER_SQL_PIL1_2526_28.sql

Option B — Via XAMPP (recommandée sous Windows) : démarrer les services Apache et MySQL depuis le panneau de contrôle XAMPP, puis ouvrir phpMyAdmin à l'adresse http://localhost/phpmyadmin. Créer une nouvelle base nommée ifri_mentorlink, sélectionner l'onglet Importer et charger le fichier FICHIER_SQL_PIL1_2526_28.sql. Configurer ensuite MySQL Workbench pour se connecter au serveur XAMPP sur 127.0.0.1:3306 avec l'utilisateur root et un mot de passe vide (configuration par défaut de XAMPP).

6
Installer MariaDB 10.11 LTS (recommandé — évite les conflits de migrations)

⚠️ Important : l'utilisation du serveur MySQL fourni par XAMPP peut provoquer des erreurs lors de l'exécution de python manage.py migrate (incompatibilités de version, encodage utf8mb4 mal géré, ou port 3306 déjà occupé par un autre service). Il est donc fortement conseillé d'installer MariaDB 10.11 LTS en autonome.

Windows : télécharger le programme d'installation depuis mariadb.org/download, choisir la version 10.11.x (LTS), et suivre l'assistant. Cocher « Install as service » pour un démarrage automatique.

# Vérifier que MariaDB tourne et créer la base de données
mysql -u root -p
-- Dans le client MariaDB :
CREATE DATABASE ifri_mentorlink CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
EXIT;

Linux / WSL :

sudo apt update
sudo apt install mariadb-server
sudo systemctl start mariadb
sudo mysql -u root -p -e "CREATE DATABASE ifri_mentorlink CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;"

Mettre ensuite à jour le fichier .env avec les identifiants MariaDB (même format que MySQL — le driver mysqlclient est compatible) :

DB_NAME=ifri_mentorlink
DB_USER=root
DB_PASSWORD=votre_mdp_mariadb
DB_HOST=127.0.0.1
DB_PORT=3306
7
Appliquer les migrations Django
python manage.py migrate
8
Démarrer Redis (temps réel WebSocket)
redis-server

Redis est requis pour Django Channels (messagerie instantanée). Laisser ce terminal ouvert.

9
Lancer le serveur de développement
python manage.py runserver
# API disponible sur : http://127.0.0.1:8000/api/
# WebSocket sur : ws://127.0.0.1:8000/ws/conversations/<id>/
Section 05

Manuel d'Utilisation

Guide à destination des utilisateurs finaux de l'application IFRI_MentorLink.

Inscription

Créer son compte étudiant IFRI.

  • Accéder à /register
  • Remplir nom, prénom, email, téléphone, mot de passe
  • Choisir sa filière et son niveau
  • Ajouter points forts et lacunes
  • Valider l'inscription
Connexion

Se connecter avec email ou téléphone.

  • Aller sur /login
  • Saisir email/téléphone + mot de passe
  • Cliquer sur « Se connecter »
  • En cas d'oubli : lien « Mot de passe oublié »
Profil

Gérer ses informations personnelles.

  • Accéder à /profile
  • Modifier photo, bio, disponibilités
  • Mettre à jour compétences / lacunes
  • Enregistrer les modifications
Publier une annonce

Proposer ou demander du mentorat.

  • Aller sur /annonces/new
  • Choisir « Offre » ou « Demande »
  • Sélectionner matière, format, disponibilités
  • Publier l'annonce
Matching

Trouver un mentor ou un mentoré compatible.

  • Accéder à /matching
  • Consulter les suggestions automatiques
  • Voir le score de compatibilité
  • Accepter ou refuser une suggestion
Messagerie

Communiquer avec son mentor/mentoré.

  • Ouvrir /messages
  • Sélectionner une conversation
  • Envoyer un message texte
  • Recevoir des notifications en temps réel
